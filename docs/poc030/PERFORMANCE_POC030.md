# Производительность

RuntimePerformance=NotMeasured. Синтетические микрозамеры UA01 не переносятся на игру.

Новый PipelineBench измеряет одним Stopwatch создание/сериализацию/hash canonical input, полный Simulation023.Step (включая geometry), сериализацию/hash обеих player projections. GC/allocated/retained и размер projections фиксируются. Это не сумма percentile отдельных стадий. Измерение исключает реальный IL2CPP-reader, Unity HUD, TCP и диск; полного runtime pipeline пока нет.

Каждый набор всего32 шага, без прогрева и повторов; cold/JIT виден в max. Недостаточно для вывода о стабильности длительного матча. Физическая карта3200×3200 и позиции/корни одинаковые между сетками. Пары infantry/IFV расположены плотно; все двигаются, часть умирает после24-го шага. Не считать это полным покрытием all-radius-changes/two-pockets/bridges/concavity/2700s stress/duplicates.

В плагине sampler4Hz, лимит обхода10000entities/8ms, cap43200samples/128MiB. При budget exhaustion данные Incomplete, не случайная выборка полного roster и не пустая армия. SamplerMetric охватывает reader+local serialization/logging, отдельно от Unity HUD/socket. Для runtime приёмки нужен общий end-to-end таймер с очередями/IO/backpressure, несколько повторов100/500/1000 и2700s; критерий frame budget должен быть согласован после измерений.
