# Установка для двух тестировщиков — FullDebugView + Launcher

Пока только поставка: запуск игры и установка мода в настоящую игру требуют отдельного разрешения.
Обоим игрокам передаётся один и тот же DynamicFrontlineLauncher.exe. Он содержит одинаковую сборку 0.4.0-T18-full-debug1. Не пересылайте interop, local-preparation или чужие ключи.

1. Сохраните EXE вне игровой папки и откройте его. Нужны Windows x64 с штатным .NET Framework 4.5+ (Windows 10/11), интернет для зависимостей и достаточно места для локальных инструментов/interop.
2. Лаунчер ищет Steam по HKCU/HKLM и libraryfolders.vdf. Если путь пуст — нажмите «Папка…» и выберите Broken Arrow. Проверка совместимости выполняется перед изменениями; несовместимая версия останавливает операцию.
3. После отдельного разрешения закройте игру, нажмите «Установить» и подтвердите конкретную папку. Portable PowerShell, pinned MelonLoader и инструменты загружаются автоматически с проверкой хешей. Interop создаётся на этом ПК. Недостающий общий Microsoft Desktop Runtime может запросить системное повышение прав. При ошибке не отключайте проверки.
4. Дождитесь завершения и нажмите «Проверить файлы». До завершения операции окно не закрывается штатной кнопкой; после аварии используйте «Восстановить после сбоя».
5. Игра автоматически НЕ запускается. После отдельного разрешения запускайте её через Steam: Anti-Cheat Disabled, штатный приватный Scenario 5454584/Airbase; параметры запуска `--melonloader.agfoffline --melonloader.agfvdumper 2022.1.0-pre-release.21`.
6. Сначала на обоих ПК LoadReadProbe, сверка собственных юнитов/посадки/смерти/spawn/реального HP и стресса, GamelogMarkerConfirmed. Только затем оба подтверждают roster.
7. По умолчанию TeamSafe. Для полного вида каждый отдельно нажимает в HUD «I CONSENT to sharing HIDDEN DATA». FullDebug включается только при двух согласиях и двух подтверждённых roster. Постоянный индикатор FULL DEBUG предупреждает, что скрытые данные раскрываются.
8. Любой игрок может отозвать согласие. Старый обмен и изображение сбрасываются; начинается новая TeamSafe-сессия. При выходе из companion lobby согласие теряется. Новому участнику требуется новое согласие. Нельзя отозвать данные, которые второй игрок уже увидел.
9. После теста нажмите «Собрать логи». Передайте только export-папку, указанную в журнале. Не отправляйте сырой Gamelog, Latest.log, токен GitHub или каталог подготовки.

## Обновления приватного репозитория

Репозиторий: IndustKocs/BrokenArrow-DynamicFrontline, Private. Встроенная версия устанавливается без токена. Для «Проверить обновления» / «Обновить» нужен доступ приглашённого GitHub-пользователя и его fine-grained token с Contents: read для этого репозитория. Введите его в скрытое поле; токен не сохраняется в файлах и не выводится в журнал. Никому не пересылайте токен издателя.

Обновление заменяет только принадлежащие установке файлы в существующей транзакции. Разные DLL/протоколы двух игроков не проходят handshake. Для нового несовместимого протокола нужен соответствующий лаунчер. Если private Release ещё не опубликован, используйте EXE со встроенной сборкой. В этой поставке публикация ещё не выполнена.

## Ошибки и удаление

Повреждённый или чужой loader/DLL не перезаписывается молча. «Восстановить после сбоя» обрабатывает незавершённый журнал, а не разрешает замену неизвестных файлов. Повторная установка может восстановить отсутствующие собственные файлы; изменённые неизвестные файлы требуют разбора.

«Удалить» спрашивает согласие. Флажок сохраняет копию настроек вне игры; снятый флажок разрешает транзакционное удаление принадлежащих моду настроек. Сторонние файлы и автоматически созданные runtime-логи не удаляются. Общий системный runtime сохраняется. Исходные общие файлы восстанавливаются из проверенных резервных копий.

EXE пока не имеет Authenticode-подписи. Сверяйте SHA256 с поставкой доверенного автора. PowerShell-команды для обычной установки не требуются; START.ps1 остаётся резервным инструментом разработчика.
