# Обязательные реальные проверки

Все пункты ниже — NotRun, пока не проведены после отдельного разрешения.

1. На чистом Windows x64: EXE стартует, находит Steam, скачивает инструменты, готовит interop и устанавливает после явного согласия; проверить UAC/недостающий runtime.
2. Оба пользователя private GitHub имеют read-доступ; опубликованный ZIP и EXE совпадают по checksum; update по API проходит без ручного удаления.
3. Штатный приватный Scenario 5454584/Airbase: серверная policy, WaitingRoomId/HostId binding, активность EOS session проверены реально. Unknown/protected — stop, не обход.
4. Steam companion discovery, native match, Relay flags/POP и отсутствие конфликта ICE0 со штатной сетью. Reconnect/host exit; никакого direct fallback.
5. GamelogMarkerConfirmed на обоих ПК, контрольная запись в фактическом FileLog. Совпадение marker не доказывает полноту всего журнала.
6. LoadReadProbe: собственный roster, ID, HP/реальный стресс, транспорт/выход, death/spawn. Обе явные roster attestations до Observe.
7. FullDebug: обе кнопки согласия, постоянный индикатор, геометрия территорий/локальных областей/ZOC/котлов, состояния и прогноз; сравнить с игровым полем, включая скрытые юниты.
8. Один отказ или отзыв согласия → TeamSafe; проверить задержки, старые пакеты, reconnect, замену второго участника и возврат в lobby. Ранее увиденная информация не может быть отозвана.
9. Реальные Unity frame time, draw calls, GC, читаемость 60×60 растеризации, узкие контуры. Автономные managed timings не равны FPS.
10. Безопасный экспорт двух клиентов, сравнение соответствующих session/input; реальный стресс отдельно от прогноза. Никаких native изменений экономики/HP/победы.

Первый опыт — только приватный 1v1. Нельзя заходить в защищённый режим ради отрицательного теста gate. При ошибке прекратить DF, сохранить безопасный export и разобрать причину, не отключая проверки.
