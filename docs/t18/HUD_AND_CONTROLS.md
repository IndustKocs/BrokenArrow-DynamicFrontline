# HUD и управление

HUD находится слева сверху. Содержит статус DF, Steam-пары, имя Steam-друга,
подтверждение его roster, синхронизацию, режим, предупреждения и состояние логирования.
Режим всегда read-only; `native effects OFF` виден постоянно.

1. DF автоматически ожидает приватный Scenario после разрешённой установки/запуска.
   Использовать штатный вариант Anti-Cheat Disabled. После ошибки или Stop доступна
   кнопка Retry; она не выключает античит.
2. Создать/войти в обычное приватное Scenario-лобби 5454584. Сеть DF подключается автоматически.
3. В первом матче работает LoadReadProbe. `Next own unit` циклически выбирает юнит
   только для HUD; сравните ID, HP, стресс и список вызванных своих юнитов.
4. После проверки транспорта, гибели и повторного появления подтвердите **свой** roster
   кнопкой `Confirm MY roster checked...`. Кнопка доступна после минимум 20 чтений и
   появления своего юнита. Эти условия не подменяют проверку оператором.
5. После двух подтверждений автоматически включается ObserveTwoClient.
6. `Map on/off` скрывает тактическую панель, `Own ZOC toggle` включает до 20 своих ZOC.
7. `Stop / disconnect` останавливает DF и выходит из его companion-лобби. Штатный матч
   продолжает управляться игрой. Повторное включение требует новой проверки roster.

Подтверждение roster не сохраняется между запусками/лобби, чтобы старое утверждение не
позволяло незаметно включить расчёты после изменения условий. Ошибки привязок, другой
сценарий, активный защищённый матч, несовместимость и неполные данные блокируют расчёт.
При недостаточных данных отсутствие фронта — ожидаемое состояние, не успешная приёмка.
