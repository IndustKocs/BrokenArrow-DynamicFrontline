# Инструкция для двух тестировщиков — preflight3

Пока только подготовка. Игра и мод ещё не проверены в реальном матче.
Обоим нужен один и тот же ZIP, Windows x64, Steam-дружба, одинаковая игра и сценарий
5454584 / Airbase. Radmin, IP, порты, сертификаты и ручные роли больше не нужны.

## Сейчас: подготовка без установки

1. Распакуйте ZIP в постоянную папку **вне игры**. Не пересылайте папку local-preparation.
2. Откройте PowerShell 7 в этой папке (если отсутствует — установить PowerShell 7 отдельно).
3. Выполните:

```powershell
.\START.ps1
```

Скрипт найдёт Steam-установку или спросит только путь к игре. Проверит файлы, скачает
инструменты по фиксированным версиям с проверкой хешей, распакует их в рабочую папку,
сгенерирует ваш interop и подготовит план. Это может занять несколько минут.
В игре ничего не меняется и ничего не запускается. Ошибка — остановка, не повод
отключать проверки или скачивать latest. Если сеть запрещает загрузку, пришлите ошибку.

Итог: local-preparation/prepared.json и install-plan.json.
Если уже подготовлены файлы, повторный запуск безопасен: проверит cache и создаст новый
interop/план вне игры. Никаких чужих interop DLL не передавайте друг другу.

## Позже: только после отдельного разрешения

Закройте игру. Установку запускает каждый игрок сам:

```powershell
.\START.ps1 -Action Install -ConfirmGameChanges
.\START.ps1 -Action Verify
```

Это отдельное согласие на мод, pinned MelonLoader и при необходимости Microsoft Desktop
Runtime 6.0.36. Недостающий системный runtime скачивается ещё при Prepare, но запускается
только при Install; Windows может запросить повышение прав. При требовании перезагрузки
скрипт остановится до установки мода. Runtime общий для программ и при удалении мода
сохраняется. Чужой loader/proxy не заменяется молча; старый RC2 сначала удаляется по receipt.

Игра автоматически **не запускается**. После отдельного разрешения на первый опыт:
штатный вариант **Anti-Cheat Disabled**, параметры Steam запуска
`--melonloader.agfoffline --melonloader.agfvdumper 2022.1.0-pre-release.21`.
Хост создаёт приватное Scenario-лобби 5454584, друг входит обычным игровым способом.
В лобби дождитесь совместимой Steam companion-пары. Канал AuthenticatedSteam
начинает подключение после входа в доказанную разрешённую комнату; политика Relay-only.
Проверьте у обоих HUD: GamelogMarkerConfirmed. Pending/Timeout/Unavailable не означают
подтверждённую запись. При ошибке session gate или Relay остановите опыт и соберите
безопасный экспорт, не отключайте проверки. ICE0 действует до выхода из игры.

Сначала LoadReadProbe: проверить свой состав, ID/HP/реальный стресс, посадку/выход,
уничтожение и новый spawn на каждом ПК. Только после проверки оба подтверждают roster
кнопкой HUD. Далее автоматически ObserveTwoClient и существующая графика фронта/ZOC.
Геометрия котлов временно отключена ради защиты скрытых данных; предупреждения
об окружении своих юнитов и отдельный прогноз остаются.
Нельзя объявлять успешную приёмку до реального двухклиентного опыта и анализа логов.

## Логи и откат

После опыта:

```powershell
.\START.ps1 -Action Collect
```

Передавайте **только созданную папку export-...**. Не raw DF logs, не Latest.log, не
local-preparation целиком, не конфиги/ключи/interop. Экспорт содержит только разрешённые
счётчики и контрольные суммы. Для сравнения двух экспортов используется команда
`dotnet bin/dev-tools/dev-tools.dll compare <export-A> <export-B>` (подготовленный portable
runtime указан в prepared.json). CoordinatorReceipt означает получение, не независимый расчёт.

Для удаления при закрытой игре:

```powershell
.\START.ps1 -Action Remove -ConfirmGameChanges
```

Если предыдущая операция прервана:

```powershell
.\START.ps1 -Action Recover -ConfirmGameChanges
```

Не удаляйте receipt/journal. Изменённые чужие файлы сохраняются с конфликтом; это требует
разбора, а не принудительного удаления. После удаления можно отдельно вернуть старый RC2
из сохранённого ZIP. Логи и общий Microsoft runtime остаются.

Полный перечень runtime-проверок и ограничений: T18B_REPORT.md.
Если установлена предыдущая сборка, сначала удалите её старым START.ps1 по receipt
(после отдельного разрешения), затем готовьте новую. Не смешивайте версии двух игроков.
