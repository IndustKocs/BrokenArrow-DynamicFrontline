# Launcher 0.4.2 — обновлённый интерфейс

Тёмный компактный WinForms интерфейс по предоставленным референсам: собственный векторный знак Dynamic Frontline, карточка тестовой сборки, золотая основная кнопка, отдельный экран настроек. Чужие брендовые изображения не использованы. Лог операций остаётся на главном экране. Основное действие выбирается по receipt: Install, Update либо Recover для Pending.

Добавлены прямые кнопки открытия GameLogs и UserData/DynamicFrontlineSteam/logs относительно выбранной папки игры. Пустой путь и отсутствующий каталог обрабатываются сообщениями. Каталоги не создаются, содержимое логов не читается. Reparse-проверка сохраняется. Safe export остаётся отдельной операцией Collect.

Предупреждение Anti-Cheat Disabled присутствует на обоих экранах. Нового запуска игры или автоматической установки нет. Подтверждения изменений, transaction/rollback, редактирование private token и автообновление сохранены. Версия мода full-debug5, payload DLL не изменяется.

Проверки: рендеры обоих экранов (--preview и --preview-settings) визуально проверены; 23 автономные проверки updater и путей логов; self-check проверенной копии EXE; ZIP inventory/embedded ZIP/payload сравниваются при выпуске. Интерактивные клики Explorer и реальная установка в игре не выполнялись. Preview не извлекает пакет, не проверяет сеть и не меняет игру.
