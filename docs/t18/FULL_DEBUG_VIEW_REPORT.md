# FullDebugView — отчёт

Основа preflight3, новый протокол df18-world-4. Simulation023, formulas и native read-only gates сохранены. FullDebug — отдельный явный opt-in; он НЕ безопасен от раскрытия скрытых данных по определению.

Согласие двух Steam companion-участников публикуется в их member data. FullDebug требует одновременно двух consent и двух roster attestations. Изменение режима меняет session binding/handshake, уничтожает старый observer/channel и очищает отображение. Протокол trusted replica повторно использует существующий CanonicalInput/ACK/checkpoint/resync; самостоятельно переписывать ядро не потребовалось. Несогласованная пара не проходит handshake. TeamSafe остаётся режимом по умолчанию и отвергает FullDebug payload.

Полная проекция включает территории обеих сторон, границы территории, ZOC всех подразделений, локальные области, полные PocketCells обеих сторон, состояния окружения/таймеры/прогнозы обоих участников. Постоянные области представлены текущей территориальной сеткой. Геометрия передаётся без намеренного исключения скрытых юнитов. Native HP/стресс/экономика/победа не меняются.

Тактическая панель использует обзорную сетку 60×60 в FullDebug (30×30 в TeamSafe). Это визуальная растеризация полного массива, не точный масштабный контур каждой исходной ячейки: узкие особенности могут сливаться. ZOC и локальные области рисуются поверх; одинаковые горизонтальные полосы заливки объединяются, чтобы сократить draw calls. Списки состояний показывают по 12 строк, перелистываются «Next own unit». Постоянный FULL DEBUG / HIDDEN DATA SHARED виден в HUD.

## Автономные проверки

87 Steam/diagnostic/session/display проверок, включая все 16 сочетаний consent/roster, полный обмен двух RuntimeObserver, совпадение ZOC и территории на одинаковом времени, сохранение всех PocketCells, отказ TeamSafe принять full payload, очистку отображения при отзыве. Старые проверки diagnostics, privacy TeamSafe, Relay и session gate сохранены.

Нагрузка: 100 юнитов, 100 построений полной managed-проекции — около 41 мс суммарно и 10.8 MB выделений на этом стенде. Это измерение подготовки данных, НЕ Unity FPS и НЕ время реального IL2CPP render. Лимиты 100 canonical units, 256×256 исходной сетки и существующие сетевые бюджеты сохранены. Не объявляется поддержка 500/1000 юнитов.

## Runtime ещё не проверен

Реальные Steam member-data задержки, отзыв согласия в живой паре, reconnect/resync с полной репликой, читаемость цветов и узких котлов, Unity draw time/GC/FPS, совпадение графики с полем и нативными наблюдениями. Контрольные суммы full replica диагностические, не доказательство правильности native read без LoadReadProbe.

Экспорт по-прежнему содержит разрешённую схему Result/статусов. DetailedReplayConsent не включается режимом FullDebug; скрытые позиции не добавляются в безопасный export. На экране и в памяти обоих тестеров скрытые данные присутствуют по их согласию; отзыв не стирает уже увиденную информацию.

Каждая смена согласия обновляет согласованный consent epoch и session binding; повторное включение FullDebug не повторяет прежний SessionHash/InputId диагностического журнала.
