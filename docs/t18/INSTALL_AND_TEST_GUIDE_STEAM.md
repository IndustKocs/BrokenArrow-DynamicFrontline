# Установка и двухклиентный тест T18

**Текущая поставка — кандидат. Ничего в настоящую игру в ходе разработки не установлено.**
Установка и запуск выполняются только после отдельного решения тестеров. Radmin/IP,
сертификаты и старая пара A/B для T18 не нужны.

## Подготовка на каждом ПК

Одинаковая поддерживаемая сборка игры: Steam build 26273833, Unity 6000.3.24f1,
сценарий 5454584 / Airbase с неизменёнными проверенными bascr/meta. Оба игрока должны
быть Steam-друзьями. Для начала — 1×1, противоположные стороны.

1. Распаковать одинаковый ZIP в постоянную папку вне игры.
2. Нужны PowerShell 7, .NET runtime 6; для генерации локального interop — прежний
   проверенный RC2 toolchain (SDK 8.0.426, MelonLoader 0.7.3, Cpp2IL и Unity archive
   с пинами из config/poc030-rc2/toolchain.json). Это не сетевые настройки.
3. Использовать собственный local-interop-manifest.json, проверенный для этой сборки,
   либо создать его скриптом `scripts/poc030-rc2/prepare-interop.ps1` и инструкцией
   `docs/poc030_rc2/INTEROP_BOOTSTRAP_A_B.md`. Interop другого ПК не пересылать.
4. Подготовить manifest, без установки:

```powershell
pwsh -NoProfile -File .\scripts\t18\prepare-steam.ps1 -InteropManifest "<свой local-interop-manifest.json>" -OutputDirectory "<новая папка подготовки>" -GameRoot "<папка Broken Arrow>"
dotnet .\bin\dev-tools\dev-tools.dll plan "<папка Broken Arrow>" "<папка подготовки>\client-manifest.json" "<папка подготовки>\install-plan.json"
```

План не пишет в игру. T18 и старый RC2 plugin нельзя загружать одновременно.
Если RC2 установлен, сначала удалить его по его receipt, сохранить старый ZIP и логи.
Не удалять чужие моды/interop вручную. Конфликт плана требует разбирательства.

## Только после отдельного разрешения установки

Закрыть игру. Установить отдельно согласованный pinned MelonLoader 0.7.3, если его ещё нет.
T18 ZIP не содержит loader, native Steam DLL и игровых interop DLL.
Применить подготовленный план:

```powershell
dotnet .\bin\dev-tools\dev-tools.dll install "<папка Broken Arrow>" "<папка подготовки>\install-plan.json" --explicit-install-consent
dotnet .\bin\dev-tools\dev-tools.dll verify "<папка Broken Arrow>" --explicit-install-consent
```

Installer сохраняет receipt/WAL от RC2 (`UserData/DynamicFrontline030/.rc2`), так как
используется проверенный транзакционный механизм. Данные самого T18 — DynamicFrontlineSteam.
Режим, роли и сетевые параметры в JSON руками не задаются.

## Первый запуск — одновременно на двух ПК

1. Использовать только штатный запуск **Anti-Cheat Disabled**, приватный Scenario.
   Loader options для локального interop остаются:
   `--melonloader.agfoffline --melonloader.agfvdumper 2022.1.0-pre-release.21`.
   Не запускать защищённый/ranked матч и не менять настройки античита средствами мода.
2. Убедиться, что HUD DF появился на обоих ПК. Хост создаёт приватное Scenario-лобби 5454584,
   друг входит через обычный игровой список/приглашение. Подождать SteamPairReady,
   сверить имя друга и отсутствие ошибки совместимости. При ошибке — логи, не обход проверок.
3. Войти в один матч. DF автоматически работает в LoadReadProbe.
4. Проверить на обоих ПК свои юниты: вызов, движение, транспорт (посадка/выход),
   уничтожение/новый spawn, реальные HP/стресс, отсутствие чужих скрытых юнитов.
   Сверять ID через Next own unit. Не подтверждать roster при пропусках/ошибках.
5. Только после успешной проверки каждый нажимает Confirm MY roster checked.
   Автоматически начинается ObserveTwoClient. Проверить свою границу, ZOC и котёл,
   неизвестный прогноз при Unknown supply; реальные игровые параметры не должны изменяться.
6. Проверить краткий разрыв Steam-соединения: stale очищает графику, resync восстанавливает
   её; ядро координатора не сбрасывает историю. Не использовать stop/новое лобби как
   доказательство resync: это другой session scope.
7. Выйти из матча, собрать логи обоих ПК через collect-logs.ps1. Приложить скриншоты
   HUD/карты и [DF] из штатного Gamelog, время теста и точное описание действий.

Для приёмки обязательны результаты реального опыта: два клиента без ручного коннекта,
один матч, автоматический запуск, видимые фронт/ZOC/котлы, статус синхронизации,
логи. Офлайн 18/18 тестов эти критерии не заменяют.

## Откат

При закрытой игре:

```powershell
dotnet .\bin\dev-tools\dev-tools.dll remove "<папка Broken Arrow>" --explicit-removal-consent
```

Удаляются только owned неизменённые файлы, общие interop/config восстанавливаются по
журналу. Логи сохраняются. При конфликте не форсировать удаление. Затем можно отдельно
установить прежний RC2 из сохранённого ZIP и своей пары; его TLS/TCP код сохранён.
