# Проекции и диагностика

Simulation.Project(team) по умолчанию не показывает круги и aggregate score. Свои Encirclement/Relief/Tau/Stress разрешены даже при скрытом противнике. OwnNotice группируется по team и переходу, не создаётся на каждом шаге.

При включении кругов используются только собственные и сейчас видимые юниты. Радиус врага повторно оценивается по видимым партнёрам: скрытый IFV не раскрывается контуром600. Потерянный контакт удаляется, ghost movement отсутствует. Public DTO не содержит enemy certificate/army values/positions скрытых юнитов/hold timers.

`preview-debug.html` и frames-debug.json содержат полную synthetic отладочную картину и не являются безопасной player-проекцией. `preview-player.html` и frames-player.json — отдельный экспорт без скрытого payload; секретные данные не прячутся лишь CSS. JS только отображает записанные C# кадры. Слой ZOC выключен по умолчанию. SVG-снимки сформированы из тех же кадров. Адаптивный HTML проверен в браузере, включая кадр10с.

IGameRadialRulerBinding — только интерфейс RuntimeRequired. Настоящая игровая линейка/tooltip и HUD не подключены. Публичный вывод итогового MatchEndIntent разрешён как результат автономного матча; политика реального сетевого HUD требует отдельного допуска.
