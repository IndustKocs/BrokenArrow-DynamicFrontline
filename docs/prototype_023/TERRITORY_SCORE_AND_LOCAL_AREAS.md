# Очковая площадь

Сетка имеет фиксированный допустимый scoringMask и worldArea=cellSize². Для команды берётся объединение persistentOwner и текущих LocalControlArea. Союзные перекрытия не удваиваются. Встречные претензии, включая local поверх persistent другой стороны, neutral при явно Experimental ConflictPolicy. Общая доля≤1.

Local footprint diff вычитает старый круг и добавляет новый, удаление убирает вклад; старые очки U остаются. OwnershipRevision инвалидирует persistent projection. Есть независимый полный Reference для малых карт. ZOC и supply напрямую не меняют Score.

Порядок synthetic шага: наблюдение состояния → локальные области/площадь на начало интервала → интегрирование ledger/ранний конец → стресс → capture на конец полного250мс шага. Захваченная в конце шага клетка начинает приносить очки со следующего. MatchEndIntent внутри шага обрезает эффекты; capture полного шага не выполняется.

Круги представлены по центрам клеток; геометрическая погрешность ограничивается пограничной полосой порядка диагонали клетки. Полный набор сравнений разных физических разрешений для всех карт не доказан. Обязательный full-match replay показывает движение острова в900/1800 без сохранения следа и без вычитания уже начисленного U.
