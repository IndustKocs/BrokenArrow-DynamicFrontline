# Изменения правил

`Legacy_022` — существующий Simulation и OperationalConnectivitySystem, сохранены для прежних сценариев. `Zoc_023/1.2` — явный новый Simulation023, не вызывает OperationalConnectivitySystem. На одном шаге не вычисляются два взаимоисключающих результата старой/новой связанности.

Новая ветка использует существующие TerritoryGrid, TerritorialConnectivity, TerritoryCaptureSystem, LocalControlAreaSystem, SpatialIndex и CombatFormulas. Новой математической библиотеки, второй установки или игровых вызовов нет.

Постоянное владение не снимается окружением или уходом. Локальная область учитывается в текущей очковой площади, исчезает при уходе и не создаёт корень. Перекрытия учитываются один раз. ZOC не захватывает землю. Разведка с legacy territoryProfileId линейной пехоты всё равно не получает захват: явный Profile023.CanCaptureTerritory имеет приоритет.

Утверждённые фазовые веса 1/2/3 применяются к новым интервалам; native destruction feed отдельный. Новые дебаффы оружия, деньги, возвраты и HP не вводились.
