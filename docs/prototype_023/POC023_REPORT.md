# PoC 0.2.3 — результат ТЗ13 v1.2

Дата проверки: 27 октября 2026. Ветка `feature/prototype-023-zoc-encirclement`, база Core022 `9243136`.

Работает автономная цепочка ZOC → геометрическое свидетельство → per-unit окружение → обслуживание → стресс → территориальный и отдельный native ledger → MatchEndIntent. Это **Synthetic / Experimental PoC, не release и не полностью принятая реализация всех 92 пунктов**.

Проверки: 284 прежние группы и 72 новые, все проходят. Четыре JSON replay успешно продолжаются из сериализованного checkpoint и дают тот же итог, что непрерывный прогон. Матч 2700 с без final-policy корректно остаётся PendingPolicy. Прорыв завершается на 120 с, развал — на 420 с. Нагрузочная матрица: 48 × 10000 обновлений; область измерения и ограничения в BENCHMARKS_POC023.md.

## Что препятствует полной приёмке

1. Геометрический spike подтверждает перечисленные тестовые кольца, одиночный танк, односторонний заслон, заполненный центр, широкий разрыв и явный мост. Он не доказывает все случаи раздела 11.4. Растровый сертификат не обеспечивает метрическую точность 99/100/101 м и диагональных щелей на произвольной местности. Проверка OpenGap — только проверка порога, не доказательство всей геометрии.
2. Прорыв использует экспериментальную ось X и поперечную ширину по Y. Это не универсальная геометрия фронта произвольной ориентации.
3. Основная нагрузочная матрица измеряет обновление поля с частотой 1 Гц при 4 Гц host, пустые локальные области и отдельный холодный геометрический запрос. Полный движущийся pipeline, плотные группы, массовая смена радиусов и локальных островов не имеют столь же длительной нагрузочной матрицы. Аллокации высоки; runtime SLA не подтверждён.
4. Нет native привязок roster/nav/service/score/endgame/radial ruler. Эти пробелы предусмотрены автономным этапом, но запрещают выдавать сборку за игровой мод.

См. REQUIREMENTS_STATUS.md для каждого из 92 пунктов. Указанные ограничения не замаскированы зелёными тестами.
