# ZOC

База400 м. Взаимная пара same-team пехота/БТР/БМП в100 м с подтверждённой локальной проходимостью получает600 м. Разные владельцы одной команды допустимы. Loaded/dead/deserting/offmap/air не источники. Один оставшийся боец остаётся допустимым. Танки не партнёры.

Пехота: soldiers×явный K; техника: strength×(.5+.5HP/maxHP); состояния1/.6/.15/0. Falloff=1 до R/2, затем2(1−d/R) до нуля вR. Порог2 и dominance1.25 экспериментальны. Профили содержат происхождение S0 и всех решений. Значение1000 существует только в явно synthetic fixtures.

SpatialIndex ищет партнёров и ближайшие пары. Field хранит footprints по UnitKey и вычитает старый вклад перед новым. Инвалидации: позиция, команда, мощность, радиус, mobility, navRevision, удаление. При неполном roster поле сохраняется, Complete=false: нельзя удалить невидимую часть кольца по частичному снимку.

PreparedTerrain — synthetic masks и portals; Local проверяет отрезок. Маска/порталы mutable только вместе с повышением Revision. Budget2000000 ограничивает топологические обходы; исчерпание возвращает Unknown. Никаких утверждений о фактическом Unity navmesh.
