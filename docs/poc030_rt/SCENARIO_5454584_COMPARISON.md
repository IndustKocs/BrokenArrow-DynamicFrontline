## Необходимые изменения для RC2

1. Подготовить отдельный проверяемый descriptor Airbase/5454584: источник Airbase.ng + именно этот bascr и его хеш, реальные playable bounds, roots по28/29 и явное соответствие команд1/7→DF0/1, passability/edges заново изAirbase. Сохранить расчётную ячейку100м; native30м — отдельная величина. До получения bounds descriptor не объявлять validated.
2. Установить источник default playable bounds по статическим данным карты либо разрешённому чтению LoadReadProbe. Альтернатива — позже явно задать проверенную игровую зону редактором, если это будет согласованным изменением сценария. Сейчас редактирование не требуется и не выполнено.
3. CanonicalWorld.cs: MapDescriptor.VerifyLocalSources сейчас жёстко требует Airport/Airport_network и SharedMissions-путь. Нужна ограниченная поддержка пользовательского сценария/его происхождения с хешами и безопасными путями; CheckObserved должен проверять выбранный контракт, native30м и команды1/7, сохраняя отказ при несовпадении.
4. compile-airport.py жёстко привязан к zone55,UID11/12,двум Airport-хешам. Адаптировать извлечение под новый контракт; не заменять только строку Map и не копировать старые маски/edges.
5. prepare-client.ps1 сейчас допускает только Airport/Airport_network. Добавить явно проверенный вариант. ProbeMod.StartReader вызывает VerifyLocalSources даже дляLoadReadProbe: одной заменой probe.json новый сценарий не заработает. Для ограниченной пробы границ потребуется отдельная fail-closed подготовка чтения без разрешения полного расчёта на неизвестной карте.
6. Проверить actual active unit profiles в выбранных колодах по существующему18-ID allowlist. Поле deckList=[] не подтверждает, что вызванные юниты поддержаны. Сами формулы Simulation023 и combat writers менять не нужно.
7. Отдельная ревизия/ZIP, новые MapHash/source hashes, одинаковый снимок сценария наA/B; offline проверки mismatch/map/root/topology и нагрузки новой области. Затем по согласованным этапам LoadReadProbe→ObserveTwoClient. Не смешивать результаты сAirport_network/007f943.

Штатная двухклиентная проба без модов может использовать этот сценарий, с отдельной фиксацией его имени/карты. Она не требует подмены MapDescriptor. Установка текущего RC2 под этот сценарий преждевременна. Фактические bounds, participant UID и динамическая навигация пока Runtime NotRun.
