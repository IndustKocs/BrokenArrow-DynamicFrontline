Дата: 30.10.2026. Пакет RC2: commit `007f943fb079c1862af9fe128b22d8d4d08e23da`. **Prepared / Runtime NotRun**. Настоящая игра, MelonLoader и сетевой матч не запускались; игровые файлы не изменялись.

Это не зарегистрированные игровые ошибки: игрового выполнения не было. RT-01–04 нельзя снять дополнительным синтетическим тестом. RT-05–06 — статически найденные пределы инструментов, не приписывать их отсутствию доступа к игре.

Остановка: отказ допуска, обязательная защита, несовпадение hash, чужой cache, generic/reader exceptions, неполный roster, разные match IDs, digest mismatch, скрытая информация HUD, превышение budget/Nmax или неожиданные native writes. Не менять guards/allowlist. После согласованного опыта закрыть обе игры, собрать минимум диагностики, recover/remove по прежнему runbook; отдельно учитывать loader inventory.
