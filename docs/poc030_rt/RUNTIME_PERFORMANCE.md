Дата: 30.10.2026. Пакет RC2: commit `007f943fb079c1862af9fe128b22d8d4d08e23da`. **Prepared / Runtime NotRun**. Настоящая игра, MelonLoader и сетевой матч не запускались; игровые файлы не изменялись.

Статус NOT_RUN. Нет игровых p50/p95/p99, FPS или live GC данных; прежняя offline матрица сюда не перенесена.

Сравнить R1 baseline и R3/R4 при сопоставимых составе, сцене и настройках. Сохранить аппаратную конфигурацию без лишних идентификаторов. Ограничение100 суммарных units, Airport100м,4Гц. Переполнение не разрешает усекать мир.

Existing metrics обрабатывает ReadMilliseconds/ReadBytes, HudLastMilliseconds/HudLastBytes, WorkerBeforeDiagnosticMilliseconds/Bytes, SourceAgeMilliseconds, IncomingQueue/OutgoingQueue, LastWireExchangeMilliseconds, UnknownGeometry. HUD — последний callback, wire exchange включает ожидание. CoreStages находятся вложенно в Result; текущий агрегатор не выводит их процентили. Из имеющихся данных нельзя восстановить отдельное время подготовки/сериализации, GC, FPS или задержку каждой очереди: эти поля отметить NotMeasured; FPS/кадровые задержки зафиксировать штатным доступным измерителем после согласия. Не подставлять worker total вместо отсутствующей стадии.

На первой короткой пробе не обещается полная приёмка всей телеметрии ТЗ. Неизмеримые поля — адресный предел диагностики. Расширение instrumentation при необходимости — отдельная ревизия и повтор сценария; не смешивать результаты. 45-минутный live soak требует отдельного согласования после короткой пробы.
