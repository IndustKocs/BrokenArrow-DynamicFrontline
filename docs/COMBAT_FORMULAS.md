## Связь с отступлением

В конструктор `DesertionController` добавлен необязательный `CalmStressRecoveryCondition`. При его наличии возврат управления требует истечения RecoverySeconds и состояния Calm, вычисленного по F02/F06 из свежего снимка стресса. Строковый CurrentStressLevel не используется как источник порогов. Коэффициенты нужно получить из проверенной конфигурации соответствующего матча; значения .5/.8 в тестах — только тестовые данные.

Это новая экспериментальная политика мода, а не найденная механика дезертирства оригинальной игры. Она не включает автоматическое отступление. Без условия сохраняется прежнее восстановление только по таймеру. Игровой плагин пока использует прежний режим: достоверного источника коэффициентов матча ещё нет.

Контроллер не применяет F03/F05 к игровому состоянию: повторный расчёт поверх штатной игры удвоил бы стресс/восстановление. Он только читает снимок. Неизвестный или некорректный стресс не разрешает досрочный возврат управления. Для ограниченного ожидания используется существующий RetreatTimeoutSeconds, отсчитываемый заново с прибытия: при его достижении без выполнения условий попытка завершается Failed с причиной `stress-recovery-timeout` и снимает блокировку. Если условия восстановления выполнены на том же вызове, восстановление имеет приоритет.

## Поддерживаемый домен и проверка

Расчёты используют float. Проверки входов — собственные ограничения прототипа, не утверждение о проверках в оригинале: конечные значения, неотрицательные величины урона/времени, положительные делители, упорядоченные коэффициенты стресса в [0,1]. F01 допускает конечные отрицательные floor/perSoldier с последующим clamp. F09 сохраняет штатное ограничение результата; остальные неограниченные переполнения отклоняются. Полная побитовая эквивалентность native/JIT не заявляется.
