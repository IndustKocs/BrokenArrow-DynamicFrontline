## Проверки и пределы

51/51 RC2 и 44/44 RC1 проходят. Проверены точный coordinator, opt-in, роли/порты, отказ для произвольного 26.* и неверных peer адресов. Скрипт pair отвергает неправильные конфигурации, а prepare-client сохраняет флаг на A/B. Два реальных автономных loopback процесса прошли TLS+канонический расчёт+disconnect/resync на Airbase. Отдельные двухпроцессные отрицательные опыты подтвердили отказ при неверном server pin и неверном HMAC key. Это не имитация PASS реальной VPN-маршрутизации: точные Radmin адреса проверены unit-level политикой и конфигурацией; фактическое межмашинное соединение проверяется network-probe на A/B.

Секреты тестов и private pair исключены из ZIP. Production pair нужно создать заново на A; PFX остаётся только на A. Никаких сетевых правил этот пакет автоматически не создаёт. Публичные listener/port-forward и отключение firewall не требуются этой инструкцией.

Со слов пользователя штатный совместный матч без модов состоялся; это recorded participant report, не новый инструментальный runtime результат. Допуск loader и loaded native readers остаются отдельными условиями LoadReadProbe.

Архив-кандидат распакован и проверен: install/verify/remove с полным локальным interop на двух sandbox, восстановление прежнего кэша и packaged replay PASS. Флаг RadminPair проверен в обоих подготовленных конфигурациях. Это два каталога одного ПК, не реальное VPN-соединение.
