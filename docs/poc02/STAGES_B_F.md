Проверены полные и неполные кадры, main-thread gate, mock ECS без setter-вызовов, 5v5, сценарная база, route status/cache/generation, смена контекста и побайтовая неизменность командных DTO при скрытых изменениях. Runtime API остаются неподтверждёнными.
