# PoC 0.2: границы разработки

База: 9a4dcb1, чистая ветка feature/frontline-connectivity. Работа ведётся в Git worktree game-integration-poc02 на ветке feature/game-integration-poc02. Исходная ветка и исследовательские документы не изменяются. Старые тесты запускаются в отдельном рабочем каталоге, результаты пишутся только под artifacts/poc02.

A: read-only инспектор компонентов и источник перечисления сущностей. B: контекст матча, идентичность, команды, профили и копируемые DTO. C: существующая FrontlineSimulation. D: отдельные минимальные командные DTO и диагностика разработчика.

Интеграционные риски, требующие явных контрактов: полное перечисление сущностей, аутентичный контекст активной базы, различие TeamUid/TeamSide/Player UID, поколения переиспользуемых сущностей, main-thread граница копирования, маршруты с неизвестным результатом, канал и маска навигации, запрет выдачи авторитетных счётчиков команде.

Технически необходимые расширения PoC 0.1 (без переписывания алгоритма):

- Отдельный CanCreateLocalArea в профиле: исходный профиль объединял право захвата и локального круга.
- Дополнительный IUnitLinkGeometry: старый ILinkGeometry получает только позиции и команду, недостаточные для ключа навигационного кэша с UID/generation/каналом и для разных профилей в одной точке.
- Явный HasInfantry/OperationallyActive в нормализованном входе: техника без InfantryUnitComponent не должна получать выдуманное число бойцов ради relay.
- Диагностический bridge не продолжает симуляцию после внутреннего исключения; публикация остаётся на последнем успешном снимке, требуется новая инициализация. Неполные/невалидные входы отсеиваются до изменения ядра.

Эти расширения обратно совместимы по значениям по умолчанию. Подтверждение — обязательный повтор всех прежних 95 тестов. Аллокации оптимизируются только после измерения; производительность тестов не называется игровым FPS.

Подтверждённость: поля HealthComponent.CurrentHealth/MaxHealth, UnitComponent.Owner/UnitData, InfantryUnitComponent.AliveSoldierCount, StressComponent, LoadedComponent и InfantryLoadingComponent статически найдены. Reflection-доступ к ref-return ECS, безопасное перечисление из UnitsPositionsTree, реальные providers контекста и работа игровых nav API требуют runtime-проверки. Native hooks и запись игровых значений отсутствуют.
