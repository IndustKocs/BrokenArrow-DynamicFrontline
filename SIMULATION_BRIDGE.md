# Simulation bridge

FrontlineSimulationBridge.Update принимает elapsed milliseconds и исполняет не более одного шага при наступлении периода (по умолчанию 250 ms). Пропущенные интервалы не вызывают неограниченный catch-up. Render FPS не определяет скорость расчёта. Источник читается на согласованном игровом потоке; мок-тест подтверждает отказ с другого потока, но фазу реального ECS необходимо установить отдельно.

Порядок: контекст → полная сырая выборка → проверка команды/DB/чисел/полей/жизни → принятие identity registry → DTO → навигационный бюджет → существующая FrontlineSimulation → сохранение результата. Неполный batch, повторная/старая revision, регресс времени и неизвестное обязательное поле не продвигают расчёт. Внутри одного снимка входные массивы копируются. LastInspection доступен при включённом сборе без симуляции.

LastGood сохраняется при отказе источника. Если исключение произошло внутри Core, rollback частично изменённого Core не обещается: bridge блокирует дальнейшие шаги этого экземпляра до переинициализации. Последний опубликованный результат сохраняется. Это предотвращает продолжение на потенциально повреждённом состоянии.

Изменение матча, карты, состава команд, базы или версии профилей сбрасывает сессию. Проверка нового профиля происходит после удаления старого состояния, поэтому ошибка нового сценария не оставляет прежний матч активным. Одна лишь navigation revision очищает маршруты, но не сбрасывает захваченную территорию. Scene change и Dispose очищают lifecycle и navigation caches; запоздалые ответы старой сессии не принимаются.

Для уменьшения аллокаций territory snapshot строится один раз; далее обновляются только ячейки delta. CellState неизменяем, массив копируется при изменении. Потребители внутренних массивов обязаны не менять их; для недоверенного потребителя предназначен отдельный сериализованный DTO. RouteEndpoint/RouteQuery/RouteResult и lifecycle entries — value types; профили индексированы один раз.

Настройки loader по умолчанию полностью выключены. EnableGameStateModification=true отклоняется. Подключение требует явного AttachReadOnlySession с проверенными providers; автоматический поиск ECS singleton не реализован. Дезертирство остаётся частью существующего автономного Core; новый loader не вызывает команды дезертирства и не меняет health, morale или владение.
