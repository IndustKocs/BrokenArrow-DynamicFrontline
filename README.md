# Dynamic Frontline — Proof of Concept 0.1

Экспериментальная кодовая база для Broken Arrow. Игровые команды **отключены в адаптере** до проверки IL2CPP-обёрток и полноты перехвата пользовательских приказов. Это не готовый к матчу мод.

Подробные результаты: [PROTOTYPE_REPORT.md](PROTOTYPE_REPORT.md). Точки интеграции: [docs/GAME_INTEGRATION.md](docs/GAME_INTEGRATION.md). Сетевая архитектура: [docs/PVP_DESIGN.md](docs/PVP_DESIGN.md).

Обновление 25 октября: в Core добавлены 10 подтверждённых формул F01–F09/F13 и опциональная проверка спокойного состояния перед возвратом управления. Сборка и 36/36 автономных тестов прошли. Условия применения и оставшиеся неопределённости: [docs/COMBAT_FORMULAS.md](docs/COMBAT_FORMULAS.md). В игровом плагине проверка стресса пока не подключена: необходим подтверждённый источник коэффициентов матча.

Из каталога проекта:

```powershell
# Только при отсутствии инструментов; скачивает архивы в tools, ничего не устанавливает в игру.
.\tools\bootstrap.ps1
# Локальная сборка и автономные тесты, без сети после bootstrap.
.\build.ps1
# Проверка оригинальной установки по ранее сохранённой исследовательской базе.
python .\verify_preservation.py
```

SDK зафиксирован в `global.json`, ссылки и хэши загрузок — в `toolchain.lock.json`. Пакеты берутся только из локального `tools/feed`. Плагин ссылается на официальный MelonLoader 0.7.3, а не на поддельные заглушки. Исследовательские dummy DLL игры в сборку не входят.

`artifacts` содержит три библиотечные DLL, журналы сборки/тестов, JSON-результаты и контрольные хэши. Никакая команда проекта не устанавливает эти файлы в игру.

Тесты — консольный runner без внешнего тестового фреймворка: при любой ошибке возвращается exit code 1. Обычный `dotnet test` не запускает этот runner; используйте `build.ps1`.

После сборки можно отдельно проверить на установленном .NET 6:

```powershell
dotnet exec --fx-version 6.0.36 tests/DynamicFrontline.Tests/bin/Release/net6.0/DynamicFrontline.Tests.dll
```

Автоматической установки, запуска Broken Arrow и изменения Steam/античита здесь нет.
