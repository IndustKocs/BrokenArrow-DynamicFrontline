# Оперативная связанность

`OperationalConnectivitySystem.Build` не читает и не изменяет владельцев территории. Он получает нормализованные подразделения, статичные корни команд, ProfileCatalog и ILinkGeometry. Граф и оценка корневой связанности отделены от логистики и территориального допуска к захвату.

Узел должен быть живым, вне транспорта, не в активном отступлении DesertionController, с положительным StatusCoefficient, разрешённым CanRelay и численностью не ниже MinimumRelaySoldiers. ShockCanRelay и PanicCanRelay отдельно регулируют подавление. Если будущая техника не имеет AliveSoldierCount, адаптер должен определить явный показатель активности для этой категории; нельзя автоматически применять пехотную численность. По умолчанию тестовый профиль Vehicle выключен.

Для поиска соседей используется spatial hash с размером корзины LinkDistance. Кандидаты берутся из 3×3 корзин. Ребро возникает при совпадении команды, расстоянии ≤ LinkDistance и положительном ответе ILinkGeometry. Корень связывается с узлом по тем же дистанционным и геометрическим условиям. Положение корней копируется в конструкторе симуляции и не меняется во время тиков.

`ConnectivityEvaluator` сначала находит компоненты BFS, затем выполняет многокорневой BFS с ограничением MaximumHops. Прямое ребро «корень → подразделение» считается одним переходом. Компонент может быть геометрически связанным, но часть его узлов не получает оперативную поддержку из-за ограничения длины цепочки. Близкий союзник без пути к корню недостаточен.

Разведка и спецназ имеют CanRelay=true, CanCaptureTerritory=false. Цепочка «линейная пехота — разведка — спецназ — линейная пехота» поддерживается, но не закрашивает коридор между узлами. Уничтожение, удаление, погрузка, паника или дезертирство посредника исключают его из следующего графа. Возвращение допустимого посредника восстанавливает связь; таймеры восстановления окружения отрабатывают отдельно.

Graph строится каждый расчётный тик; spatial hash сокращает поиск, но в плотной группе все узлы могут оказаться соседями, и худший случай остаётся квадратичным по числу рёбер. Инкрементальный кэш графа и ограничение плотных связей — направления оптимизации, не скрытые обещания текущего PoC.

GridLinkGeometry проверяет прямую линию через клетки маски с запретом срезания непроходимого угла. Это консервативное геометрическое ограничение, а не поиск обходного пути. Можно передать другой ILinkGeometry, включая проверенный игровой маршрут. UnrestrictedGeometry предназначен для тестов без препятствий.

Интерфейс `ILogisticsConnectivity` не используется графом и вызывается только при сборке состояния подразделения. TestLogistics хранит явно заданное множество снабжаемых UnitKey: оперативная связь сама ничего в него не добавляет.
